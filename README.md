# 介绍
现在查看长安大学的青春长大官网的活动并不是很方便，例如：不能按更多条件筛选活动，也不方便查看课程冲突情况，收藏功能也迟迟不上线。而且在列表中查看完活动会自动回到顶部，又要重头往下翻找，且加载缓慢。针对此，我自己制作了一个青春长大活动筛选器。

需要注意的是，本筛选器功能仅限查看活动，不支持在这个工具里面报名活动或签到。使用筛选器需要用浏览器（不能在QQ里面在线打开，浏览器需启用JS）；**工具使用AI制作。**

# 二、.ics日历文件帮助

.ics文件是通用的日历日程文件格式。接下来将以WeekUp课程表和MyCHU为例展示在手机上如何导出.ics日历文件，并导入到工具。

## WeekUP课程表

它是一款好用的课程表软件（https://www.wakeup.fun/ ），支持从教务系统一键导入课程。在导入好课程，并设置好上课时间后，可以点击页面顶部的选择。选择并记住导出的位置。

## MyCHU

由Rinn.大佬开发，为长大人定制的一站式平台，整合了学校的各种平台和工具，强烈推荐！！（[Github](https://github.com/RinnMoe/my_chu) ；[官方文档](https://docs.qq.com/doc/DWVBtVU1QS2xvaHpZ)）

进入软件，完成统一登录认证后，点击底部“课表”按钮查看课标页。在右上角选择三个点，选择导出-日历文件（.ics），保存到自己可找到的地方（另外一个方法是，选择分享到QQ的自己，进入QQ对应聊天，选择文件下载，此时会默认下载到`Download/QQ`目录下）

## 导入

打开工具-高级筛选，找到你的刚刚导出的.ics文件，选择即可

# 更新日志

## v1.0

- **有更强大的筛选与搜索功能**：可以按积分、校区、持续时间筛选活动；可以筛选未报满活动；有更强的日期筛选功能；支持一键筛选符合自己报名限制的活动
- **有更贴心的时间安排方案**：可以收藏活动，并查看冲突活动；支持导入.ics日历并判断日程冲突情况（例如，weekup课程表可以导出课程表到ics日历，在此导入可规避课程）；活动信息快速显示星期几；可以按时段筛选活动
- **有更贴心的细节设计**：置顶显示相较上次新增的活动；平铺式显示活动信息，避免来回切换；可一键去官网查看活动；简介中有群号的，可以一键进群
- **有更流畅的使用体验**：无需频繁加载与来回切换页面

## v1.1（11.16）

- 【新增功能】
	- 新增“类别”筛选，可多选“补录”“比赛”，并支持“只看”和“不看”两种方式。以便于针对性地筛选活动。
	- 新增“加日程”功能，可将活动导出为.ics日历文件，并支持普通提醒、响铃提醒、多个提醒时间及自定义分钟数。
- 【优化功能】
	- 补充了更多的校区地名，活动自动区分南北校区的标记更加精准。
	- 调整“长期”活动界定策略（由大于3小时改为大于4小时），同步调整活动时长筛选为。
	- 优化了刷新时的速度，部分刷新转为后台静默更新。
	- 过期活动清理调整为清除“结束超过14天且未报名”的活动。
	- 活动详情中的报名限制显示上移，便于快速知晓自己是否受限。
- 【问题修复】
	- 非图片附件不再显示无意义的图片预览区域，只保留文件名和下载入口。
	- 统一活动底部按钮样式，修复“进活动群”等按钮文字错位。
